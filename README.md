# Maruti K15B Powertrain CAN Telemetry & Physical Plant Emulator

A real-time simulation and CAN 2.0A telemetry broadcasting suite modeling the physical dynamic and network communications of a Maruti/Suzuki 1.5L K15B-inspired 4-cylinder engine plant.

---

## 1. Specifications
* Displacement: 1.5L (1,462 cc) 4-cylinder
* Idle Speed: 750 RPM
* Cold-Start Fast Idle: 1,100 RPM
* Nominal Coolant Temp: 88.0 deg C
* Bus: CAN 2.0A (100 ms cyclic rate)
